## 🌟 專案簡介 (Overview)

本專案專為國小四年級學生、教師與家長打造，將 115 課綱自然（四上）全冊課程內容轉化為深受小朋友喜愛的**「手繪可愛風彩色鉛筆繪本心智圖筆記系統」**。

全站包含：
* 🎨 **13 張全套統一純手繪風格圖卡**：彩色鉛筆素描筆觸、奶油水彩紙紋理、擬人化可愛腮紅角色與 3D 彩虹緞帶標題。
* 🕹️ **太陽、地球、月球公轉與月相動態模擬器**（第 2 版：太陽在右側標準教科書視角，支援時間軸拖曳、60 FPS 流暢運轉與 8 大月相快速點選）。
* 🎬 **高畫質科普動畫教學影片 (MP4 & GIF)**：內建播放器與直接下載功能。
* 💡 **各小單元記憶口訣、易錯迷思避雷針與隨堂折疊式互動快問快答**。
* 🖨️ **一鍵列印與友善排版**：支援學生自修與教師隨堂測驗印製。

## 📚 課程目錄與 13 張圖卡架構 (Curriculum Structure)

### 🌌 第一單元：閃亮的天空（全單元 3 張筆記卡）
* **1-1 一天的天空**（太陽方位與高度角、指北針使用、竿影長短方向變化規律）
* **1-2 月亮的位置**（觀測月亮仰角量角器、拳頭測量法、地物參考點、月亮東升西落）
* **1-3 月相的變化**（農曆初一新月、初八上弦月、十五滿月、二十三下弦月週期循環）

### 💧 第二單元：水域環境（全單元 4 張筆記卡）
* **2-1 認識水域環境**（流動水域 vs 靜止水域、淡水/鹹水/半鹹水、野外安全守則）
* **2-2 水生植物**（挺水性荷花、漂浮性布袋蓮氣室、浮葉性睡蓮、沉水性水蘊草）
* **2-3 水生動物**（魚鰓呼吸與五大鰭、青蛙變態發育、水黽表面張力、龍蝨攜帶氣泡）
* **2-4 珍惜水域環境**（水汙染優養化、外來種入侵危害、節水愛地球綠色行動）

### 🧪 第三單元：物質變變變（全單元 3 張筆記卡）
* **3-1 影響物質變化的因素**（流水磨圓鵝卵石/沙石沉澱、風吹水面波動、酵母發酵膨脹、潮濕空氣鐵生鏽、形態改變 vs 產生新物質）
* **3-2 溫度對物質的影響**（巧克力受熱融化/冷卻固化、冰塊奶油可逆循環、高湯冰磚保鮮、雞蛋加熱變熟蛋不可逆質變、線香燃燒灰燼）
* **3-3 酸與鹼對物質的影響**（酸性檸檬汁/食醋、鹼性肥皂水/小蘇打水、紫色高麗菜遇酸變紅/遇鹼變藍綠、安全實驗不嚐試）

### 🔔 第四單元：聲光世界真有趣（全單元 3 張筆記卡）
* **4-1 聲音的產生與傳播**（鼓面米粒跳動/聲帶/音叉水花振動發聲、空氣傳播五色鳥叫、水中敲不鏽鋼筷、耳朵貼桌聽敲擊、紙杯土電話拉直棉線）
* **4-2 光的直進與反射**（太陽/電燈/燭火是光源、光被阻擋形成影子、直軟管看見光/彎軟管看不見、鏡子反射光路/月球反射太陽光、汽車遮陽板/反光背心/道路反光裝置）
* **4-3 聲音和光的應用**（語音搜尋/火災警報器/垃圾車音樂、太陽能路燈/燈塔指引/交通號誌、警車警示燈+鳴笛/平交道閃光+警鈴/煙火、萬花筒三面鏡多次反射美麗對稱圖案）

## 🚀 如何佈署到 GitHub Pages (Deployment Guide)

只要 3 步即可將本網站發布到網路上，供學生與家長直接瀏覽：

### 步驟 1：建立 GitHub Repository
1. 登入 [GitHub](https://github.com/)，點選右上角 **New repository**。
2. 設定專案名稱（例如：`grade4-nature-mindmaps`）。
3. 設為 **Public（公開）**，**不要勾選** Initialize with README（我們本地已有完整檔案）。
4. 點擊 **Create repository**。

### 步驟 2：推動本地檔案到 GitHub
在專案根目錄開啟 PowerShell 或終端機，執行以下指令（或直接執行本專案附帶的 `push_to_github.bat`）：

```bash
# 1. 加入所有檔案
git add .

# 2. 提交初始版本
git commit -m "feat: 國小四年級自然手繪心智筆記與公轉模擬器 v1.0"

# 3. 更名預設分支為 main
git branch -M main

# 4. 關聯到您的 GitHub 儲存庫 (請將 YOUR_USERNAME 與 REPO_NAME 替換為您的名稱)
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

# 5. 推送上傳
git push -u origin main
```

> 💡 **一鍵指令檔**：您也可以直接雙擊執行目錄中的 `push_to_github.bat`，程式會自動引導您貼上 GitHub 網址並一鍵推送！

---

### 步驟 3：開啟 GitHub Pages 免費網站託管
1. 進入您剛建立的 GitHub 倉庫頁面，點選最上方的 **Settings**（設定）。
2. 在左側選單點選 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch**：
   * 選擇 **`main`** 分支。
   * 資料夾選擇 **`/(root)`**。
   * 點選 **Save** 儲存。
4. 等候約 1~2 分鐘，重新整理頁面，頂部就會出現您的專屬網站網址：
   ```
   https://YOUR_USERNAME.github.io/REPO_NAME/
   ```
5. 點擊該網址，即可在電腦、平板、手機上直接開啟完整的互動心智圖與公轉模擬器！
